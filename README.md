Sistema de Gestión de Torneos – GKA
Descripción
Base de datos desarrollada en SQL Server para gestionar los torneos internacionales de la Global Kitesports Association (GKA).

El sistema permite administrar torneos, participantes (kiters), inscripciones y resultados de competencias realizadas en diferentes lugares del mundo.

Este proyecto fue realizado para la materia Bases de Datos 2, aplicando conceptos de modelado relacional y programación en T-SQL.
